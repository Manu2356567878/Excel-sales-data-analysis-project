# Sales Performance Dashboard | Microsoft Excel

##  Project Overview

An interactive **Sales Performance Dashboard** built in Microsoft Excel to analyze **1,000 sales records** across years, regions, countries, product categories, and order priorities.

The project transforms raw sales data into business-focused insights using **Pivot Tables, Pivot Charts, Slicers, and KPI-style summaries**.

##  Objectives

- Analyze yearly revenue trends
- Compare revenue across regions and countries
- Analyze revenue and cost by region
- Identify revenue contribution by order priority
- Compare product-category performance
- Extract actionable business insights from sales data

##  Tools & Technologies

- **Microsoft Excel**
- Pivot Tables
- Pivot Charts
- Slicers / Interactive Filtering
- Data Cleaning & Preparation
- KPI Analysis
- Business Intelligence & Data Visualization
